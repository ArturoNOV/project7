# Vehicle Sales Dashboard

This project is a web application developed with Streamlit to explore a dataset of used vehicle advertisements in the United States.

The application provides interactive visualizations created with Plotly, including:

- A histogram showing the distribution of vehicle mileage.
- A scatter plot showing the relationship between vehicle mileage and price.
- Interactive controls that allow users to display the different visualizations.

The project also includes a basic exploratory data analysis (EDA) performed in a Jupyter Notebook.
